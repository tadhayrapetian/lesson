# English lessons

Сайт с уроками. Урок открывается только после кода из письма.

## Как это работает

1. Ученик открывает урок, вводит свою почту и нажимает Send code.
2. На почту приходит 6-значный код. Он действует 10 минут, ввести его можно 5 раз.
3. После правильного кода урок открывается. Пока вкладка открыта, другие уроки открываются без нового кода (до 4 часов).
4. Если ученик закрыл или обновил вкладку, нужно запросить новый код.

Код приходит только на адреса из списка `private/students.txt`. Остальным сайт отвечает, что их нет в списке.

## Вход для учителя по паролю

Учителю не нужен код из письма. На экране входа нажми **Teacher login** и введи свою почту и пароль.
Пароль хранится в Netlify в переменной `ADMIN_PASSWORD`, в коде его нет. После 5 неверных попыток вход по паролю закрывается на 15 минут, код по почте при этом работает.

## Отправить урок ученику (только для учителя)

1. Открой урок и войди своей почтой (той же, что в `GMAIL_USER`, или в `TEACHER_EMAIL`, если она задана).
2. На тёмной панели сверху появится кнопка **Send to student**. Ученики её не видят.
3. Выбери Homework или Lesson, укажи почту ученика, имя, срок сдачи и заметку (всё, кроме почты, можно не заполнять).
4. Нажми Preview email, чтобы посмотреть письмо, затем Send.

Письмо оформлено в цветах урока (поле `theme` в `public/lessons.js`) и подписано именем из `SITE.name`.
Ученик, которому отправили урок, автоматически получает доступ к сайту, вписывать его в `students.txt` не нужно.
Такие ученики хранятся в Netlify: Data & Storage → Blobs → `students`. Чтобы закрыть доступ, удали там его запись.

## Тексты сайта

Всё, что написано на главной (о себе, факты, соцсети, тарифы), лежит в `public/lessons.js`, в блоке `SITE`.
Заявки из формы Book a lesson приходят на почту учителя. Ответ на такое письмо уходит прямо ученику.

## Домашка от ученика

В каждом уроке у ученика есть кнопка **Submit homework**: он пишет ответ, прикрепляет файлы (лишний можно убрать) и нажимает Send to teacher.
Тебе приходит письмо «Homework from …» в цветах урока, с ответом и файлами во вложении. Нажми «Ответить», и ответ уйдёт ученику.

## Где что лежит

- `public/` — то, что видно всем: главная страница и список уроков (`lessons.js`).
- `private/lessons/` — сами уроки. Напрямую по ссылке их не скачать, сервер отдаёт урок только после входа по коду.
- `private/students.txt` — почты учеников, по одной на строку (плюс те, кому учитель отправил урок).
- `netlify/` — серверная часть: отправка и проверка кода, выдача урока.

## Как ученик получает доступ

1. Человек заполняет форму Book a lesson или выбирает тариф на сайте.
2. Тебе приходит письмо с заявкой. Нажми «Ответить», договоритесь об оплате.
3. После оплаты нажми в том же письме кнопку **Give … access** и подтверди на сайте. Кнопка работает 30 дней.
4. Ученику приходит письмо с инструкцией. С этого момента его почта получает коды.

Посторонние почты кода не получают: сайт отвечает, что уроки только для учеников, и предлагает выбрать тариф.

## Добавить или убрать ученика вручную

Войди в любой урок как учитель (Teacher login) и нажми **Students** на тёмной панели сверху.
Там можно добавить почту (по желанию с письмом-инструкцией) или убрать ученика. Убранный ученик сразу теряет доступ.
Отправка урока через Send to student тоже даёт ученику доступ.
Почты из `private/students.txt` тоже имеют доступ; убрать их можно только в этом файле.

## Добавить урок

1. Загрузи HTML-файл в `private/lessons`. Имя файла — это slug, например `travel-stories.html`.
2. В `public/lessons.js` добавь блок с тем же slug (`slug: 'travel-stories'`). Поле `theme` задаёт цвета письма.
3. Commit changes. Через минуту урок появится на сайте.

Ссылка для ученика: адрес сайта + `#slug`, например `https://САЙТ.netlify.app/#small-joys`.

## Настройки Netlify (Project configuration → Environment variables)

- `GMAIL_USER` — почта, с которой уходят коды.
- `GMAIL_APP_PASSWORD` — пароль приложения Google (16 символов, без пробелов).
- `SESSION_SECRET` — длинная случайная строка, никому не показывать.
- `ADMIN_PASSWORD` — пароль учителя для входа без кода.
- `TEACHER_EMAIL` — необязательно. Почта учителя, если она отличается от `GMAIL_USER`.
